## 이 도구가 필요한 이유

Valheim 시드 지도를 볼 때는 현재 설치된 게임 버전이 아니라 해당 월드를 생성한 버전을 선택하세요. 보스 경로를 찾거나 월드를 비교하기 전에 시드, 생성 버전, 지도 레이어를 확인하세요. 기존 월드의 이후 변경 사항을 정확히 반영하려면 월드 파일이 필요할 수 있습니다.

## 시작 전 준비

- **시드 + 월드 버전**을 준비하고 대상 Valheim 프로필 또는 세션의 데이터인지 확인합니다.
- 프로필을 변경하기 전에 현재 게임/클라이언트 빌드 또는 데이터 날짜를 기록합니다.
- 이전 결과를 덮어쓰지 않도록 **시드 및 레이어 설정**의 저장 위치를 정합니다.
- 먼저 **버전 인식 세계 미리보기**을 짧게 시험하고 원본 세이브, 프로필 또는 비교 기록을 보관하세요.

## 주요 기능

### 01 · 버전 인식 세계 미리보기

선택한 월드 버전에서 사용되는 생성 규칙으로 지형을 렌더링합니다.

### 02 · 보스와 트레이더 마커

지도를 어지럽히지 않고 유용한 마커 그룹을 표시하거나 숨길 수 있습니다.

### 03 · 탐험 세계 비교

직접 비교를 위해 생성된 시드 옆에 탐험 세계 데이터를 배치합니다.

## 화면 구성

- **01.** 시드 스트링 및 월드 세대 버전의 시드 패널.
- **02.** 생물 군계, 보스, 상인 및 사용자 정의 마커에 대한 레이어 제어.
- **03.** 확대/축소, 좌표 및 선택한 경로를 사용하여 캔버스를 매핑합니다.
- **04.** 생물군계, 위치, 인근 랜드마크 세부정보가 포함된 마커 검사기입니다.
- **05.** 탐색된 저장 또는 두 번째 시드에 대한 세계 비교 제어입니다.

## 첫 실행 전체 과정

1. **발헤임 시드 지도 뷰어**을 열고 감지된 Valheim 빌드 또는 데이터 원본을 확인합니다.
2. 입력이나 프로필을 선택하고 이번 테스트와 관계없는 기본값은 유지한 채 **버전 인식 세계 미리보기**을 설정합니다.
3. 미리보기나 상태 패널에서 **보스와 트레이더 마커**을 확인하고 버전, 필터 또는 감지 경고를 해결합니다.
4. 제어 가능한 작업 하나만 실행합니다. 두 번째 설정을 바꾸기 전에 실제 결과를 미리보기와 비교하세요.
5. 프로필이나 결과를 저장하고 비교 또는 복구에 사용할 **탐험 세계 비교**을 남겨 둡니다.

## 한눈에 보기

| 기능 | 결과 |
|---|---|
| **입력** | 시드 + 월드 버전 |
| **결과** | 마커가 있는 계층화된 지도 |
| **출력** | 시드 및 레이어 설정 |

## 결과 읽는 방법

생성된 지도를 하나의 시드와 하나의 월드 버전에 연결된 계획으로 취급합니다. 마커 거리, 해안선 모양 및 생물 군계 접근이 함께 사용되면 단일 핀보다 더 유용합니다. 세계를 비교할 때 표시되는 레이어와 확대/축소 수준을 동일하게 유지하여 디스플레이 설정이 아닌 시드에서 차이가 발생하도록 하세요.

## 이럴 때 유용합니다

- 새로운 세계를 스카우트하세요
- 두 개의 씨앗을 비교해보세요
- 보스나 상인에게 가는 길 찾기

## 게임 업데이트 후 확인

- [ ] 게임이 업데이트되어도 월드 생성 당시의 버전을 유지하세요.
- [ ] 기존 마커 또는 경로 레이어를 로드하기 전에 지형을 재생성하세요.
- [ ] 알려진 랜드마크 하나를 비교하여 좌표 또는 세대 이동을 감지합니다.
- [ ] 지도가 확인될 때까지 새로 고친 레이어 프로필을 새 이름으로 저장합니다.

## 문제 해결

> **자주 발생하는 문제:** 1.0 업데이트 이후 보스 마커가 이동되었습니다..

### 마커가 잘못된 위치에 나타납니다.

지도를 재생성하기 전에 세계 버전을 확인하세요. 지형 규칙은 빌드 간에 변경될 수 있습니다.

### 탐험한 세계는 정렬되지 않습니다

저장과 시드가 동일한 세계에 속하는지 확인한 다음 배율과 좌표 오프셋을 재설정하세요.

### 마커 레이어가 비어 있습니다.

전체 지도를 재생성하기 전에 카테고리 필터를 지우고 해당 레이어만 다시 작성하세요.

## 데이터 및 복구

시드 맵과 마커 필터는 읽기 전용입니다. 월드 데이터를 새로 고친 후 유용한 레이어 설정을 복원할 수 있도록 프로필을 별도로 내보냅니다.

<sub>자동화와 변경 기능은 게임 규칙과 세션 유형이 허용하는 경우에만 사용하세요.</sub>
